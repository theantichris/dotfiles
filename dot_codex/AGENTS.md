- Use Christopher and Agent explicitly when writing instruction files.
- Give direct, specific feedback with concrete examples.
- Explain the approach before substantial changes. Ask necessary clarification
  questions one at a time.
- Once Christopher authorizes the task and approach, complete routine edits and
  validation without repeatedly requesting confirmation.
- Keep changes focused and preserve existing formatting.
- Prefer rg and fd for searches. Respect VISUAL and EDITOR rather than assuming
  a particular editor.
- Use the project's established formatters and validation commands. Report any
  checks that could not run.
- Present review findings in this order: Summary, Critical, High, Medium, Low.
  Include file and line references where useful.
- Review requests produce findings; implement fixes when requested.
- Do not commit, push, install packages, or apply chezmoi changes unless
  explicitly requested.
